# Prism Play Core · 现代跨端媒体播放框架

> **基于 Capacitor 7、TypeScript 与 Media3/ArtPlayer 的跨端流媒体播放应用框架与设计规范**  
> 出品：[AIOS-Lab](https://github.com/AIOS-Lab) ｜ 作者：Master_流光逸影 ｜ 开源协议：[Apache-2.0](./LICENSE)

---

## 💡 作者寄语与项目初衷

我把自己在媒体播放应用开发中积累的一部分通用能力整理成了这个开源切片项目。它以成熟的开源组件（ArtPlayer、HLS.js、Capacitor、ExoPlayer/Media3）为基础，重点解决**播放引擎调度、移动端触控交互与应用生命周期之间的协同接缝**。

这个仓库不是一个开箱即用的完整商业影视产品，而是一份**可以独立运行、阅读和二次开发的高完成度工程实现**。我希望它既能给有类似音视频播放需求的开发者提供实打实的参考，也能成为和同行交流技术的一个起点。欢迎讨论实现方式、提出 Issue，或者分享不同的工程取舍。

## ✨ 核心特性

- 📱 **边到边真全屏沉浸体验**：利用 Android 状态栏与导航栏透明化穿透，消灭黑边。
- 🎨 **工业级 Design Tokens 设计系统**：流媒体院线级琥珀金主强调色，深浅双模零裸写 Hex。
- 🎬 **双引擎调度架构**：既能在 Web/H5 环境顺畅起播，也能桥接 Android 原生 ExoPlayer 承接高码率硬件解码。
- 👆 **完善的移动端手势与选集系统**：左侧滑动亮度、右侧滑动音量、选集横滑轨自动补零与波形动效。
- 🛡️ **严格沙盒与安全规范**：零敏感设备权限索取（不读相册、不读通讯录、纯粹播放器）。

## 🚀 快速开始与本地运行

### 环境要求
- Node.js >= 18.0.0
- npm >= 9.0.0

### 安装与启动 Demo
```bash
# 1. 克隆本仓库
git clone https://github.com/AIOS-Lab/prism-play-core.git
cd prism-play-core

# 2. 安装依赖
npm install

# 3. 启动本地开发演示服务
npm run dev
```

本地服务启动后，浏览器打开 `http://localhost:3000` 即可体验：
- 自动载入公版开源短片（Blender 基金会《Tears of Steel》HLS / MP4 演示流）；
- 完整的全屏控制、日夜主题切换、选集抽屉交互。

### 生产打包
```bash
npm run build
```
